# Angelechy Guide

A living Yu-Gi-Oh! TCG guide for Angelechy: the meta, your list, lines through hand traps, Endgame Problem lines, every matchup, and siding plans with odds.

## ▶ Open the guide: https://nickllages.github.io/angelechy-guide/

## In a browser (phone or computer)
1. Open **https://nickllages.github.io/angelechy-guide/**.
2. On a phone, save it so it opens like an app:
   - **iPhone (Safari):** tap Share → **Add to Home Screen**.
   - **Android (Chrome):** tap ⋮ → **Add to Home screen**.
3. Tap **Sections** (top right) for the menu. The home page has buttons for **Browse matchups**, **Siding plans**, **Your decklist** and **Endgame lines**.
4. Reload to get the latest version. The guide is updated after research runs.

## In the GitHub app
1. Open the GitHub app and sign in.
2. Go to **Home → Repositories → angelechy-guide**.
3. Tap the website link under the description, **nickllages.github.io/angelechy-guide**, or the link at the top of this README. The guide opens in your browser.
4. Tip: tap **Star** on this repository, and it will always be under **Home → Starred**.

The app shows this repository's files. The guide itself is the web page, and it only displays properly through the link.
