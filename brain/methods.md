# Methods — how to get data, and how the guide is built, tested and published

## Getting data

**Card texts and TCG status**
- `https://db.ygoprodeck.com/api/v7/cardinfo.php?name=<exact>&misc=yes` (or `fname=<partial>`, or `id=1,2,3`).
- `banlist_info.ban_tcg` is missing when a card is Unlimited. `misc_info[0].tcg_date` gives the release date.
- Python's urllib needs a browser `User-Agent` header (403 without one); curl works as is.
- Card texts collected so far are in `data/cards_tech.json` and `data/cardtexts.txt` (published as `raw/card-texts-*.md`).

**Tournament decklists**
- **Search:** `https://ygoprodeck.com/api/decks/getDecks.php?name=<deck>&format=Tournament%20Meta%20Decks&limit=20&offset=0` (send `Referer: https://ygoprodeck.com/`). It returns `deck_name`, `tournamentName`, `pretty_url`, `submit_date`.
- **Read a list:** `python3 tools/ydk.py <deck urls…>`. It parses the card IDs embedded in the page (`maindeckjs`/`extradeckjs`/`sidedeckjs`) and resolves names.
- **Never trust WebFetch summaries of deck pages**; they invent card names.
- **Events:** `https://ygoprodeck.com/api/tournament/getTournaments.php`, event pages `/tournament/<slug>`.
- **yugiohmeta API:**
  - Find the deck id: `https://www.yugiohmeta.com/api/v1/deck-types?name=<Deck%20Name>&limit=1`
  - Then: `https://www.yugiohmeta.com/api/v1/top-decks?ocg=false&incomplete=false&deckType=<id>&limit=30&page=1&sort[created]=-1`
  - Use curl `-g` with a browser User-Agent. A snapshot is in `data/recent_tops.json`.

**YouTube**
- Search pages and channel search pages parse (look for `ytInitialData` videoRenderer); a channel's Videos tab doesn't. DB Grinder: `https://www.youtube.com/@TheDBGrinder/search?query=angelechy` (`tools/ytchan.py`).
- **Captions:**
  1. Open the video in the built-in browser and **mute it first** (`video.muted=true`, volume 0, `movie_player.mute()`, store `yt-player-volume` as muted).
  2. Skip ads.
  3. Hook fetch/XHR for `timedtext` and reload the captions module (`movie_player.unloadModule('captions')` / `loadModule('captions')`).
  4. Pick the English track with `setOption('captions','track',{languageCode:'en'})`; it once defaulted to Bengali.
  5. Leave the video paused afterwards.
- Only use lists posted after the newest set's release. Record the player's **reasons** for cards and siding; that's the valuable part.
- Never bypass paywalls (Metafy).

**Analysis**
- **Hypergeometric:** `P(≥k of K in n from N)`. The guide has a calculator (#calc); in Python, use `math.comb`.
- **Hand simulation:** `tools/sim.py` (BASE = the current main; it scores playable and hand-trap-proof openings).

## The guide

**Sources**
- The page is `guide/angelechy-guide.html`. Backups are `guide/.backup-*.html`.
- **Matchup deep dives:** data in `build/mu_v2_*.py`; render with `python3 build/render_matchups.py` (re-runnable).
- **Siding rows:** generated by the newest `build/side_*.py` (currently `side_oct14.py`). Each is a one-time script with explicit per-matchup plans plus checks: balanced swaps, availability, never Opposition, single copies and e4 kept going 2nd. Write a new dated script for each change and keep the old ones as history.
- **v3 layer (Oct 13):** navigation, the Learn pages and the Tools pages come from `build/v3/{learn,cards,handtraps,tools}.html`, `v3.css` and `v3.js`, inserted by `python3 build/v3_apply.py` (re-runnable; it replaces marker blocks). **Never hand-edit those blocks in the guide.** A new top-level page needs an entry in `v3.js` AREAS.
- **Don't re-run** the old one-time scripts `build/v2.py`, `v2_ui.py` or `restructure.py`.

**Testing**
- **Scripted check:** `build/v3test.sh NAME tracker 900 1300 test` runs 26 checks (navigation, life points, tracker, search) in headless Firefox (flatpak) and writes PASS/FAIL to `build/shots/NAME.png`.
- **Screenshots:** `build/v3test.sh NAME <hash> 390 844` for a phone, `… 1400 900` for desktop.
- **Custom tests:** `HEADJS=file.js` injects into the head (for example, force reduced motion); a 5th argument `js:file.js` appends a test script. The coin/die checks are in `build/v3/frames/`.
- **Headless gotchas:**
  - Opening a URL with `#anchor` makes Firefox scroll, and the screenshot then draws sticky bars at the scroll offset. The harness passes the hash as `?h=` to avoid that.
  - Animations don't advance in a hidden tab.

**Publishing**
1. **The artifact:** https://claude.ai/artifact/9EaHDydVbJ9GjcgHrFi5F5. Publish with `url` and the same file path. If a newer version exists (the daily task publishes too), read the artifact first, merge, then publish; never force without the user's OK.
2. **GitHub Pages:** `bash tools/publish_site.sh` builds `site/index.html` and pushes `index.html`, `.nojekyll` and `README.md` (from `tools/repo_readme.md`) to nickllages/angelechy-guide with `~/.local/bin/gh`. It then pushes the brain. Pages takes about 30–60 s to update.
3. **Brain:** `python3 tools/push_brain.py` (one commit for all of `brain/`).

**Daily task:** `~/.claude/scheduled-tasks/angelechy-meta-watch/SKILL.md`. It researches, merges non-deck findings, proposes deck changes in its run summary, and appends to `brain/log.md`.

## Tools in the guide (Oct 13–14)

- **Life points:** localStorage keys `ag-lp-v1` and `ag-timer-v1`.
- **Match tracker:** key `ag-tracker-v1`; a swappable `Store` object, ready for a backend.
- **Coin and die:** randomness is `crypto.getRandomValues` XOR `Math.random`, with rejection sampling. The coin motion is sampled physics (thumb flick, gravity arc with constant spin, bounce, settling rattle). Verify fairness with `build/v3/frames/verify*.js`.
- **Deckbuilder (#sim, Oct 15):** card list `data/carddb.json` built by `python3 tools/build_carddb.py` from the YGOPRODeck API (TCG cards only; rows `[id, name, type, zone 0 main monster/1 spell/2 trap/3 extra, hand-trap guess, TCG status 0–3]`, plus alt-art ids). It's published as `cards.json` beside the page: on the artifact via `files: {"cards.json": "data/carddb.json"}` (keep passing it on every publish), on GitHub Pages by `publish_site.sh`. Rebuild after every Forbidden & Limited list. The default deck is the `MAIN`/`EXTRA`/`SIDE` constants in `build/v3/v3.js` (keep them in sync with the user's list); card jobs (`POOL`) and the hand rules are ported from `tools/sim.py`. Saved decks: localStorage `ag-decks-v2`. Tests: `build/v3/frames/anytest.js` (17 checks) with `HEADJS=build/v3/frames/carddb-head.js`.
- **Odds calculator (#calc):** moved from Siding to Tools on Oct 15; the markup is still the original `#calc` section.
